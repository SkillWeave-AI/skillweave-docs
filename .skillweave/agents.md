# SkillWeave planning helper

This repository does not hold a durable planning backlog. The organization-wide
source of truth is `skillweave/skillweave-planning` on Forgejo. Repository-local
`.skillweave` data may be used only as ephemeral execution state; durable work
items, status, and handoffs belong in the central planning repository and are
synchronized with the relevant Forgejo issue by `skillweave-ops`.
